# GHOSTLIGHT — a stealth game

A thief slips through the Meridian Museum at night. Four guards walk
fixed patrol loops with vision cones; crates are the only cover; the
exit glows in the far corner. Reach it unseen — or get caught trying.

Play it: open `game/index.html` in a desktop browser. WASD or arrows
to move, Shift to sneak, Enter to start, R to restart. Grab the three
artifacts on the risky routes if you dare — the meter fills fast when
a guard sees you, and a full meter raises the alarm. Break line of
sight and it cools down again.
